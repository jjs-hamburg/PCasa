The PCasa release packaging step replaces that default runtime with the
pinned non-static upstream vips-dev-x64-web-8.18.7.zip distribution,
which provides 38 native DLLs including separate GLib, libexif, libheif,
librsvg, FriBidi and Pango libraries. All are SHA-256 checked against the
archive with SHA256 3a122eb3d588690008216f786338e2f9329dba3c3c2768b5933cf7299d549241.
The exact DLL hashes and names are in libvips-dynamic-files.csv.
The original native license notices are still included under
Packages/NetVips.Native.win-x64-8.18.7/. DLL replacement alone does not
supersede other applicable source, copyright or notice requirements.

The CEF SHA256 refers to the previously audited Windows publish payload.
The dynamic libvips SHA256 is from the SHA-pinned upstream release file
and a successful Windows CI extraction; actual installer files are checked
byte-for-byte against the new publish payload before release.
