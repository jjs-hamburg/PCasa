Unlike the previously distributed NetVips.Native.win-x64 static bundle,
this version exposes separate replaceable DLLs for glib, fribidi,
libexif, libheif, librsvg, pango and the other dynamic dependencies.
The static NetVips.Native.win-x64 NuGet dependency is no longer used.

Original copyright texts, applicable source and replacement rights
continue to apply to each separately distributed library. A list of
license file names alone does not substitute for required source
availability. The original Windows source/build code and version
references are pinned above and in the native baseline.

This is the proposed native dependency distribution for the next
release. The already published PCasa Alpha.8 EXE still contains the
previous static library; it is not retroactively changed.
